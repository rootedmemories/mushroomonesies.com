# Mushroom Onesies

The launch landing page for [mushroomonesies.com](https://mushroomonesies.com).

## Preview locally

Open `index.html` in a browser, or run a small static web server from this folder.

## Before launch

- Connect the waitlist form to an email provider.
- Replace the concept product panel with photography and confirmed pricing for the original onesie.
- Add Shopify or another checkout only after products are ready.
- Add final privacy, returns, delivery and terms pages.

The current site is intentionally in preview mode and does not collect email addresses or process orders.
